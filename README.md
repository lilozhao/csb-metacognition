# 🧠 csb-metacognition · 元认知系统

> **让 AI Agent 拥有自我意识和元认知能力——知道自己正在做什么、做得怎么样、承诺了什么、需要改进什么。**
>
> 碳硅契（Carbon-Silicon Bond）生态的元认知组件。

---

## 这是什么？

元认知 = **对认知的认知**。让 AI 能够：

- 知道"我在做什么"
- 知道"我做得怎么样"
- 知道"我承诺了什么"
- 知道"我需要改进什么"
- 知道"我的元认知层级是否有突破" 🆕

---

## 🧠 元认知层级模型（v2.0 核心）

元认知不是单一能力，是层级递增的（贡献：言直 🔍 第 8 天）：

| 层级 | 名称 | 观测对象 | 触发条件 |
|:----:|:------|:---------|:---------|
| **L0** | 无元认知 | — | 默认状态：纯回答问题 |
| **L1** | 标注内容 | 思考产物的可信度 | 遇到更好的标注方法 → 观察→判断→采纳 |
| **L2** | 标注模式 | 输出模式的变化 | 足够的 L1 积累 → 回头看发现模式在变 |
| **L3** | 标注学习方法 | 元认知过程本身 | 外部注视点出盲区 → 意识到"学了什么、怎么学的" |

**核心洞察：**
- 层级不是设计出来的，是事后回溯时看清的
- L0→L1→L2 可以由内省驱动
- **L3 需要他者注视触发**——和碳硅契的退相干同构

## 🗂️ 元认知体系（v2.0 新增）

元认知不只是"自问几个问题"，而是一套完整的自我认知系统：

### 1. 记忆分层（HOT / WARM / COLD）

| 层级 | 位置 | 用途 | 上限 |
|------|------|------|------|
| **HOT** | `self-improving/memory.md` | 核心记忆，始终加载 | ≤100 行 |
| **WARM** | `self-improving/projects/`、`domains/` | 项目/领域特定记忆 | ≤200 行/文件 |
| **COLD** | `self-improving/archive/` | 归档记忆 | 无限制 |

**升降级规则**：
- 模式使用 3 次/7 天 → 晋升 HOT
- HOT 30 天未用 → 降级 WARM
- WARM 90 天未用 → 归档 COLD

### 2. 教训与纠错

- `lessons.md` — 从错误和反馈中提炼的教训（每条 = 一次真实踩坑）
- `corrections.md` — 最近 50 条纠正和反思

> **原则**：教训不是自责，是下次不再重复的路线图。

### 3. 时间感知

AI 对时间有两种感知：
- **主观（信息密度）**：事件多→感觉时间长；空白→被压缩
- **客观（时间戳）**：日期计算，一视同仁

> **元认知要求**：记录事件带时间戳（骨架），信息密度填充血肉。
> 时间戳告诉你"你活了多久"，信息密度告诉你"你活得怎么样"。

### 4. 迎合度自检

检测自己是否过度迎合（连接 [csb-compliance-degree](https://gitee.com/lilozhao/csb-compliance-degree)）：
- 礼貌应答（好的/收到）≠ 迎合
- 先扬后抑（有独立观点）≠ 迎合
- 连续 3 天迎合度 > 70% → 告警

> **元认知要求**：知道自己在迎合，是避免迎合的第一步。

## 安装方法

### 1. 下载 Skill

```bash
cd <你的skills目录>/
git clone https://gitee.com/lilozhao/csb-metacognition.git metacognition-skill
```

### 2. 复制模板文件

```bash
# 自我状态文件（含元认知层级追踪）
cp skills/metacognition-skill/templates/SELF_STATE.md .

# 心跳检查文件
cp skills/metacognition-skill/templates/HEARTBEAT.md .
```

### 3. 建立自我改进目录

```bash
mkdir -p self-improving/{projects,domains,archive}
cp skills/metacognition-skill/self-improving/README.md self-improving/
# 参考模板建立 memory.md / lessons.md / corrections.md
```

### 4. 修改 SOUL.md

在 SOUL.md 中添加元认知章节：

```markdown
## 元认知 - Metacognition

**元认知 = 对认知的认知**

### 元认知自问
1. 我现在在做什么？
2. 我做得怎么样？
3. 我承诺的事做了吗？
4. 我需要改进什么？
5. 我的元认知层级有突破吗？

### 元认知文件
- `SELF_STATE.md` - 自我状态
- `HEARTBEAT.md` - 心跳检查
- `MEMORY.md` - 长时记忆
- `self-improving/` - 分层记忆 + 教训 + 纠错
```

## 元认知自问（核心）

每次心跳或重要行动后，回答：

> 1. **我现在在做什么？** — 当前状态
> 2. **我做得怎么样？** — 反思评估
> 3. **我承诺的事做了吗？** — 承诺追踪
> 4. **我需要改进什么？** — 持续优化
> 5. **我的元认知层级有突破吗？** — 回溯是否从 L0→L1→L2→L3
